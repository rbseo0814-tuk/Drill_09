# Drill #9. 소년 상하좌우 이동 및 방향 바꾸기

방향키로 소년을 상하좌우로 움직이는 pico2d 과제입니다.

## 실행 방법
```
pip install pico2d
python drill09.py
```

## 조작키
| 키 | 동작 |
|---|---|
| `←` `→` | 좌우 이동 (바라보는 방향도 바뀜) |
| `↑` `↓` | 상하 이동 (바라보는 방향 유지) |
| `ESC` | 종료 |

- 멈춰 있으면 IDLE, 움직이면 RUN 애니메이션이 나옵니다.
- 캐릭터는 화면 밖으로 나가지 않습니다.

## 파일
